# ChordNote
Trabalho Final de Fundamentos de Programação

Funcionalidades:
Registrar acordes como compassos em musicas
Editar esses acordes
Ver esses acordes em notas (Ex: Cm7 => C Eb G Bb)
Transpor esses acordes em semitons.

Menu: 
1 - Listar músicas
2 - Visualizar música
3 - Criar música
4 - Excluir música
5 - Atualizar música
6 - Transpor música
7 - Limpar Tela
0 - Sair
